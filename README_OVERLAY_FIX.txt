BRKLIVE19 Overlay Fix
======================

Fixed:
- Scorer buttons now publish every saved score/overlay state through Firebase,
  localStorage, BroadcastChannel, and a direct window/iframe postMessage bridge.
- Overlay listens for the direct scorer bridge and sends an OVERLAY_READY message.
- Overlay Firebase listeners are safely guarded when Firebase is unavailable.
- Index-generated overlay URLs include bridge=3.

How to use:
1. Open index.html and select a match.
2. Open the scorer and open the Live Display/Overlay.
3. Press scoring or overlay buttons in scorer.
4. The overlay should update immediately.

For OBS/browser source, use the Overlay URL generated by Index. Keep the scorer
and overlay on the same deployed site/origin when possible. Firebase remains the
cross-device transport.
